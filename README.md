# Task Manager App (React + TypeScript) 📝

A lightweight, type-safe task management application built with **React.js**, **TypeScript**, **Context API**, and **Tailwind CSS**. Designed for organizing daily workflows with persistent local storage.

## 🚀 Live Demo
🔗 [View Live Application](https://react-ts-todo-app-five.vercel.app/)

## ✨ Key Features
* **Type-Safe Codebase:** Built with TypeScript to ensure strict typing for states and task models.
* **Global State Management:** Utilizes React's **Context API** for efficient state distribution without prop drilling.
* **Data Persistence:** Automatically saves tasks to `localStorage` to keep data across sessions.
* **Responsive Design:** Clean, intuitive UI designed using Tailwind CSS.
* **CRUD Operations:** Easily create, toggle completion, and delete tasks.

## 🛠️ Tech Stack
* **Language:** TypeScript
* **Library:** React.js
* **State Management:** Context API
* **Styling:** Tailwind CSS
* **Storage:** Browser LocalStorage
* **Deployment:** Vercel
